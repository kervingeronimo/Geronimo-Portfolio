Reflection

During the creation of this portfolio, several challenges surfaced — and each taught me something new. One of the biggest hurdles was ensuring the layout was responsive across different devices. At first, elements would break or overlap when viewed on small screens. To solve this, I revisited CSS Flexbox and Grid and used media queries to adjust font sizes, margins, and component stacking. Testing on real mobile devices also helped uncover layout issues that emulators didn’t show.

Another challenge was organizing my code cleanly. As features were added (like navigation, project cards, hover effects), the CSS and JavaScript files became harder to maintain. To manage this, I refactored by extracting shared styles into utility classes and modularizing JavaScript functions into smaller, reusable pieces. This improved readability and ease of debugging.

If I were to improve the portfolio next, I would add dark mode / theme toggling, integrate a blog or case studies section where I discuss design decisions, and include animations or transitions more subtly to elevate the user experience. I’d also want to gather user feedback by asking friends or peers to browse the site and report usability issues. Finally, I’d host my own custom domain and deploy continuous integration so updates are seamless and professional.
